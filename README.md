# Dev Excuses Library 🤷‍♂️

Uma biblioteca Node.js para salvar desenvolvedores em apuros gerando desculpas altamente críveis (ou não).

## Como usar
\`\`\`javascript
const { getRandomExcuse } = require('./dev-excuses');

console.log(getRandomExcuse('bug')); // Retorna uma desculpa para bugs
console.log(getRandomExcuse('prazo')); // Retorna uma desculpa para atrasos
\`\`\`
